# 零件标准、设计校核与 DVP&R 联动

本次专题题录复核：2026-10-13。覆盖 DVP&R 当前 38 类产品；新增 28 项国家/ISO/IEC/IPC 专题题录。原有标准库记录仍采用原复核日期，不能把本次专题复核理解为整个库重新确认最新版本。

## 来源和适用原则

- 本次新增仅采用国家标准与 ISO/IEC 官方发布资料，以及用户明确指定的 IPC 电子互连标准。IPC 是国际行业标准，不是 ISO/IEC 国际标准；LV/USCAR/UL/ASTM/内部经验是既有来源，保留但分类标明。
- 只索引标准号、题录、用途、适用边界和发布机构链接，不保存标准正文。IPC 基础编号不锁定任意修订字母，采购和设计定版时核对修订表、附录和匹配版本。
- 设计指南是工程建议，验证项目是起始矩阵。标准方法、材料试样性能、零件设计要求与成品验证不等同，所有采样、严酷等级、寿命、限值仍由适用产品标准及项目受控文件确定。
- ISO 1817:2026 已替代2024版；GB/T 1040.1-2025 已替代2018版；ISO 3386-1:2025 取代旧1986版。本次避免继续推荐这些旧版本。

## 数据和 UI

新增共享文件 `js/part-design-data.js` 在 `standards-dvpr-supplement.js` 后、标准库页面和 `dvpr-data.js` 前加载，提供：

- `PART_DESIGN_LIBRARY.records`：标准库题录，同时补入 DVP 标准字典；新增体系受测试白名单约束。
- `PART_DESIGN_LIBRARY.guide(product)`：按产品 ID 选择对应设计模板，返回产品类别、推荐标准和校核项。
- 每项包含稳定 `id`、`item`、`standard`、`design`、`verification`、`boundary` 与九列 `profile`。此 profile 就是 DVP 验证行来源，不维护两份相互独立的指南/矩阵。
- `DVPR_LIBRARY.designGuides` 保存全部当前产品的指南；`products[].designGroup` 为展示分类，不修改原始产品 ID 或底库类别。

产品分为结构件、电气件、标准件、密封与热管理、隔热与缓冲、材料与工艺、安全部件。目标标准按 GB/ISO/IEC/IPC/LV/USCAR 等来源分类。未选组默认折叠，已选组在重新渲染时展开；折叠不清除选择。

指南页选择产品会显示相关标准、设计关注点、对应验证与适用边界；计划页勾选产品会同步指南对象。单项/整组“加入DVP”采用同一 profile，自动选中产品和所需标准，但不替用户判定合格。

状态新增 `view` 和 `guideProduct`，兼容旧 JSON/草稿缺省值；模型继续使用 version 2。去重除了保留既有 `sourceKey`，还识别有来源行的产品/项目/标准组合，防止旧 profile 索引变动后重复添加；用户自行复制的无来源行仍允许保留。

原有内部工作簿 446 条经验记录不删除。通用验证按适用范围筛选：裸板不再套连接器 IEC 60512 绝缘方法；非电气产品不套 ISO 16750 气候负荷；既有传感器 EMC 条目更正为窄带辐射抗扰主题。

## 维护与验证

新增产品应显式补充 family/template 映射，而不是依靠兜底总成指南。新增标准必须核对官方题录及适用范围，在 record 中写复核日期和 source；改版涉及材料范围或方法时同时修订 checks、profile 与推荐。

新增测试：`tests/part-design-data.cjs` 检查全部产品指南与真实DVP行对应、目录和来源范围；`tests/dvpr-design-guide.cjs` 检查分类选择、切页、单项/整组去重、旧索引兼容、草稿恢复与窄屏。

## 同义验证项合并

`js/dvpr-merge.js` 提供浏览器/CommonJS 两用 `DVPRMerge.mergeRows(rows)`，生成、指南加入、Excel/PDF/JSON导出采用同一逻辑；工作区另有“合并重复验证项”，可整理已有工程。只处理同一产品ID和产品名称，不跨零件合并。

识别通用/内部/交叉参考/指南之间相同名称及明确的同义主题，例如盐雾、载流温升、外观尺寸、绝缘电阻。未知自定义主题只按名称匹配，不使用宽泛的编辑距离来删除项目。高低温存储、稳态/循环湿热、单件/总成、老化前后、整车/换电站及不同明确载荷、电压、温度、时长/方法保留独立；不同执行状态、责任人、日期或报告记录也不强行合并。

合并行保留全部标准引用、试验前后测量、方法、边界、判据和样品分配。不同内容按来源列在同一单元格，绝不按最大/最小值自动决定采用哪个标准；相同文字只显示一次。合并是整理验证计划，不表示来源标准等效或一次试验可覆盖全部方法。

`mergeSources` 是可JSON往返的来源快照，帮助重复生成去重；允许缺省以兼容旧文件。人工修改后的工作区内容优先于快照，不从旧快照恢复旧判据。执行信息和附件保持，完全相同的附件只保留一份；内部底库的原始446条数据不改写。

新增回归：`tests/dvpr-merge.cjs` 验证语义、条件保护、来源、人工修改和幂等；`tests/dvpr-merge-browser.cjs` 验证FPC温升合并、5A/8A过流分开、旧工作区整理、自动导出和来源/附件JSON往返。

相关既有测试：`tests/dvpr-browser.cjs`（导出/附件）、`tests/dvpr-internal-database.cjs`（经验记录保留）、`tests/standards-library.cjs`（筛选/官方域名）。这些测试对折叠内控件应等待 attached 再展开分类，不应要求全部产品默认可见。
