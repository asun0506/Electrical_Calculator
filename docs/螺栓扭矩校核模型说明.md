# 螺栓扭矩与连接界面校核

更新：2026-10-15。依据用户提供的《主继电器安装扭矩校核20250508.xlsx》可见工作表 V3.0 的单元格公式和条件格式，不依据截图上的四舍五入值反推公式。不修改或随网页发布原工作簿。

## 输入与显示

深蓝色：公称直径 D（mm）、定义扭矩 T（N·m）、质量 m（kg）、冲击加速度 a（g 倍数）、数量 n、接触外径 A / 内径 B（mm）、界面屈服应力 σy（MPa）。报告标题、名称等仍用普通样式。

黄色：综合工况系数 c=1.3、振动衰减 v=0.6、扭矩公差 δ=12.5%、摩擦 μ=0.18、屈服许用比例 η=0.75；以及可覆盖的螺距 P、螺纹中径 d₂、摩擦项 I₁、螺距项 I₂。后四项留空为自动，输入数值为手动覆盖，清空恢复自动。有效参数和覆盖状态在过程与报告中显示。

P 自动表：M4=0.7、M5=0.8、M6=1、M8=1.25、M10=1.5 mm，来自 E26 / D33:H35。其他直径需要手动输入 P；d₂ 自动计算而非采用底部舍入后的参考值。K 在 Excel E31 本身是派生参考输出，不是主计算输入，页面不将其误用为独立扭矩系数。

结果绿色代表该行通过、红色代表不通过，同时显示文字判定，不能只靠颜色判断。无效/缺失参数会清除旧的绿色结果并显示待完善。载荷校核可关闭，此时不要求质量和加速度，也不输出通过的载荷判定；保留已输入内容以便重新启用。

## 公式与 Excel 对照

轴力使用 kN、长度使用 mm，故 **kN × mm = N·m**。以下为原表公式的等价表示。

| 结果 / 单元格 | 公式 |
| --- | --- |
| 平均接触直径 Dᵦ | (A+B)/2，来自 E29 中的 0.5×(E14+E13) |
| d₂ / E27 | D−0.6495P |
| I₁ / E29 | μ(0.577d₂+0.5Dᵦ) |
| I₂ / E30 | P/(2×3.1415926) |
| 名义轴力 F₀ / G19 | T/(I₁+I₂) |
| 最大 / 最小轴力 G20 / G21 | F₀(1±δ/100) |
| 接触面积 S / E17 | 3.14(A²−B²)/4 |
| 界面屈服载荷 Fy / E18 | σyS/1000 |
| 许用屈服载荷 Fsafe / E19 | ηFy |
| 允许扭矩 / G6 | Fsafe(I₁+I₂) |
| 单颗最小所需轴力 / G11 | mac/(nv×100) |
| 所需屈服载荷 / G18 | F₀/η |
| 所需屈服应力 / G15 | (F₀/η)×1000/S |
| 最小许用面积 Smin / G17 | Fmax×1000/σy |
| 最小允许外径 / G13 | 2√[Smin/3.14+(B/2)²] |
| 最大允许内径 / G14 | 2√[(A/2)²−Smin/3.14]；根号内为负时无可用内径，判定失败 |
| 名义屈服利用率 / G32 | F₀/Fy，与 η 比较 |
| Kref / E31 | T/(FsafeD)，仅参考，不参与 T→F 主公式 |
| I₁,ref / G29 | T/Fsafe−I₂，仅参考 |

保留原表的 π 近似常数。载荷式 `/100` 对应 g≈10 m/s² 后从 N 换为 kN；a 的单位是 g 倍数，不是 m/s²，也不额外叠加 1g。衰减 v 位于分母，不能当作旧版的振动放大系数相乘。扭矩上下限均由 E25 的 12.5% 计算，不使用 H20 文字备注里的“15%”。

### 原表差异及明确处理

1. G10 是固定数值 1，不含公式。页面改为 `nreq=max(1, ceil[mac/(v×100×Fmin)])`，比较 `n≥nreq`，防止大载荷时仍显示只需一颗。
2. 原表最小面积和内外径按 Fmax / σy、不含 η；最小屈服应力按 F₀ / η。页面保留这些口径以复现附件，同时显示解释。综合结论必须包含原表 G20 的 `Fmax≤Fsafe` 检查，不能只凭绿色尺寸项判定通过。
3. G6 与 T 比较，G13 与 A 比较，G14 与 B 比较，G15 与 σy 比较，G17 与 S 比较，G20 与 Fsafe 比较，G11 与 Fmin 比较，G32 与 η 比较。通过边界均包含等号，使用很小的相对数值容差避免浮点舍入把等号误判为失败。
4. E31 的 Kref 以“许用轴力”作分母，不是 `T/(F₀D)`；因此不能用它再次计算实际预紧力。I₁/I₂ 手动覆盖后直接用于主公式，过程同时显示自动参考值和实际采用值，不伪造公式等号。

## 兼容与边界

仅保留 `calculationModel: 'workbook-v3'`，项目 schema 3。按用户明确要求，旧 K 算法、界面选择器、旧过程和未加载的 `js/calc-bolt.js` 直接删除，不提供迁移。导入 schema 2 / 旧 K 工程会提示不再支持，且不覆盖当前工程；旧模型草稿不套用到新模型，显示重新填写提示。

公式使用固定版本 KaTeX 0.19.0 和 `js/math-render.js`，JS、CSS、字体及 MIT 许可均随仓库离线打包，不依赖 CDN。LaTeX 以 `trust:false` 渲染，固定模板与已校验数值分别处理；不把用户名称/备注当作 LaTeX 命令。工程公式页的 63 张卡片也采用显式 LaTeX，不再用 HTML/斜杠正则猜测分式。

库的接入依据：[KaTeX 本地浏览器部署](https://katex.org/docs/browser.html)、[渲染与安全选项](https://katex.org/docs/options)。字体目录须与库 CSS 的相对引用一致，新增离线版本时核对官方包完整性并保留许可。

过程、结果、报告采用 `toPrecision(4)` 的四位有效数字（不是四位小数），必要时使用科学记数法；保留尾随零，例如 5.000、29.80、0.2167。整数数量与公式定义常数不人为改写。舍入只发生在显示层，轴力、边界和红绿判定使用完整计算精度；近似结果以 LaTeX 的约等号表示。

仍保留报告→部件→连接界面、附图、JSON、自动草稿、中英文打印与 PDF。新计算核心为纯函数 `js/bolt-torque-core.js`，由入口在 UI 前加载，不增加网络依赖或后端。

此工作簿主要校核**连接界面材料承压与外载所需夹紧力**，没有提供螺栓本体的完整强度模型。绿色结果不涵盖螺栓本体拉伸/扭转、剪切、弯矩、夹持刚度、疲劳、摩擦散差和防松；旧算法的螺栓本体应力结果也不替代完整连接设计验证。
