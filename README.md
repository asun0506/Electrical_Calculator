# 电气工程师计算器

当前版本：**v2.1.1**。最近修改与历史记录见 [修改日志](CHANGELOG.md)。

纯静态、离线优先的电气与机械工程工具，包含 19 个计算、知识库及工程文档模块。无需后端或构建步骤，双击 `index.html` 即可使用；`Electrical_Calculator.html` 为兼容跳转入口。

## 使用和备份

保留整个文件夹及其目录结构，不能只复制 HTML。用浏览器打开入口后，从左侧导航选择电气计算、机械校核、知识库、估价或文档生成模块；Excel 导出组件、图片与资料均在本地打包。

输入和工程保存在当前浏览器的本地存储 / IndexedDB 中，不会自动上传。本地文件、不同网站域名、不同浏览器之间的数据互不共享。清理站点数据、隐私模式或浏览器回收存储可能导致丢失，自动保存不能替代文件备份。

开发分支新增的功能内多项目和全量备份（尚未发布，产品版本暂不变）：

- 各计算/校核/工程文档页面顶部可命名、新建、复制、重命名和切换项目。新项目从默认模板开始；切回旧项目或刷新后可继续工作。同名的不同功能项目彼此独立，不增加顶层业务项目。
- “恢复当前项目默认值”只影响当前项目；项目管理删除需确认且至少保留一个项目。材料库、标准库和公式页保持公共资料页，用户材料不会随项目清空。
- 左侧“备份与恢复”可选择授权目录，一键将所有功能已存项目、当前编辑、公共用户材料、查询状态和附件保存为分层时间快照。不自动双向同步，不覆盖历史备份。
- 也可下载相同目录结构的 ZIP；页面显示“备份包已生成”不代表浏览器确认磁盘已经保存，请检查下载文件。目录方式逐文件读回校验后才标记完成。
- 恢复先检查快照目录或 ZIP，再选择项目。默认另存副本；替换必须明确选择同功能目标并再次确认。公共材料、查询和设置另行勾选，默认不覆盖。恢复前自动留恢复点；已有后续编辑时不允许直接回退覆盖，可另存旧项目副本。
- 若浏览器工作区损坏或冲突，普通保存保持阻止；从有效备份恢复时需明确确认重建，原始记录随重建工作区保留，未选的备份内容不会自动恢复。报告生成中切换项目会取消本次异步导出，避免串入其他项目的数据。
- 目录访问依赖浏览器支持和授权，重开后可能需要再次授权；不可用时使用 ZIP。选择“检查快照目录”时应选择包含 `manifest.json` 和 `complete.json` 的那一级时间目录，不是所有快照的父目录。

首次启用会保留有效旧草稿为“原有项目”；不同历史单例另存“历史项目”，损坏/不支持数据隔离保留。旧 K 算法数据不迁移到新螺栓校核。报告源文件仍可使用各模块原有 JSON；PDF/SVG/Excel 是交付结果，不能替代可编辑备份。

备份包含当前浏览器中已有的工作内容，不包含程序代码、未导入浏览器的磁盘文件、标准正文和以前下载到磁盘的报告。ZIP 限制 100 MiB、解压后 200 MiB、最多 10000 条目；单 JSON 10 MiB，图片仍按模块既有限制校验。校验用于发现损坏，不能把来源不明的备份视为可信。详见[备份验证与手工检查说明](docs/workspace-backup-validation.md)。

- 汽车零件估价：“当前零件”导入导出只影响正在编辑的零件，“整个项目”包含项目内全部零件。材料和工序参数修改只影响项目，不会回写静态底库；行情、工时、良率和采购条件需自行复核。
- 电气间隙 / 爬电距离：支持电芯、模组、PACK 三级边界、关键尺寸、截图和尺寸链。判定可选 RSS 3σ / 4σ / 6σ 或极值法；完整 JSON 包含图片与尺寸链。清空需确认，大量图片可能达到浏览器存储上限。报告支持 Word `.doc` 和浏览器打印 PDF。
- 原理图：通过 JSON 保存 / 迁移整个工程；SVG / PDF 是绘图交付格式，不能替代可编辑项目备份。
- 电池包 RLC：提供电阻、电感、简化 RL 短路响应和电容储能估算，不替代实测、保护验证或完整标准认证；详见 [模型说明](docs/电池包RLC校核模型说明.md)。

## 开发接手

其他 AI 助手与开发者请先阅读 **[完整开发与 AI 协作交接文档](README_AI开发交接.md)**。其中包含全部模块地图、计算与数据约定、保存和导出机制、原理图架构、测试命令、多 AI GitHub 协作与发布流程。

用户运行不需要 Node.js；开发验证使用 `pnpm install --frozen-lockfile` 与 `pnpm test`。浏览器测试有 Windows Chrome 路径条件，跨平台接手请查看交接文档的测试章节。

数据保存在用户自己的浏览器中，请定期导出项目源数据或全工作区备份。既定网页发布方式为 GitHub `main` + Cloudflare Pages；本次开发未自动推送或发布。
