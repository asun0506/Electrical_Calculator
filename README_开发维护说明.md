# 本地综合计算器开发维护说明

## v1.6.1：SOR 章节化填写与原位附图

- 适配 2026-08-27 更新的公开版 `SOR Template.docx`，按模板正文顺序识别 34 个填写表格。
- 填写项按大章节归类、按章节号排序，并在每个文字项和表格上显示所属章节；章节标题本身不再被误识别为输入项。
- 所有表格统一为白底编辑样式，均可新增或删除行；新增行后保持当前章节展开。
- 模板中标有“（附图）”的单元格可原位上传 PNG/JPG，图片随 JSON 保存并嵌入生成的 Word/PDF 对应单元格。
- JSON 数据格式升级至 v3，仍兼容旧版没有原位图片数据的项目文件。

## v1.6.0：适配公开版表格化 SOR 模板

- 模板源更新为可公开的 `SOR Template.docx`，并提供 `scripts/build_sor_template.py` 进行可重复构建。
- 33 个标黄表格直接映射为表格式填写界面：14 个固定信息表、19 个支持增减行的清单表。
- 保留 23 个正文填写项、A4 页面、页眉页脚、目录字段、图片与原始样式；生成 Word 时自动请求更新目录。
- JSON、Word、PDF 预览与附件能力继续保留；封面 SOR 编号和版本自动同步到页眉。

## v1.5.2：SOR 封面信息合并

- 将模板解析产生的 19 个同名“文档封面与基本信息”卡片合并为一个集中章节。
- 合并后保留封面、项目、合作方、文档基本信息和响应/偏离说明表，一键填充会同时恢复这些内容。
- 目录条目不再显示为用户输入项；清空、JSON 导入和 Word 生成时会自动保留模板目录占位内容，打开 Word 后仍可更新整个目录。

## v1.5.1：绝缘距离多 Sigma 判定

- 尺寸链默认保持 RSS 3σ，每条关键尺寸可独立切换 RSS 4σ、RSS 6σ 或极值法。
- 现有 RSS 合成值视为 3σ，由 `σ = RSS / 3` 派生 4σ 和 6σ；极值法仍按各公差贡献绝对值直接累加。
- 页面表格、公差带图、Word/PDF 报告均同时列出 3σ/4σ/6σ/极值参考，并以用户所选方法重算最小尺寸与结论。
- JSON 仍使用 `schemaVersion: 1`；旧项目缺少判定方式时自动补为 RSS 3σ。

## v1.5.0：SOR 文件生成器

- 新增基于原始 DOCX 版式的 SOR 文件生成器，按章节引导填写模板标黄字段。
- 目录不作为输入项；Word 打开时提示更新目录和页码。
- 14 个关键表格支持按原行样式添加/删除多行，并提供章节级模板默认值恢复。
- JSON 导入导出会保存全部字段、动态表格和附件；图片附件可插入 Word/PDF 附件页。
- Word 直接修改原模板包，保留 A4 纵向、公司页眉页脚、双语样式、图片和表格版式。
- PDF 使用本地 Word 预览渲染后按 A4 打印，无需上传文档。
- 电气间隙/爬电距离报告补充明确的 A4 横向毫米尺寸，Word 与 PDF 页面比例一致。

本工具是无后端、无构建步骤的静态 HTML 项目，可直接编辑后刷新浏览器验证。

## 入口与模块机制

- 网站入口：`index.html`
- 兼容入口：`Electrical_Calculator.html`（自动跳转至 `index.html`）
- 公共样式：`css/styles.css`
- 注册与导航框架：`js/app.js`
- 每个 `js/calc-*.js` 文件是独立子计算器，通过 `ElectricalToolkit.register()` 注册。
- 汽车零件估价模块：`js/calc-part-estimator.js`
- IEC 60664 基础标准数据与单层算法：`js/calc-iec60664.js`
- 电芯/模组/PACK 三级系统校核与报告：`js/calc-iec60664-system.js`
- 估价底库：`js/estimator-data.js`
- Excel 离线导出组件：`js/vendor/xlsx.min.js`
- 估价底表参考：`docs/超级估价模板_工序组合扩充版.xlsx`

## 修改估价底库

`js/estimator-data.js` 暴露只读基础数据 `window.PART_ESTIMATOR_DATA`，其中包含：

- `materials`：原材料
- `processes`：工序
- `packaging`：包装
- `processTemplates`：标准工艺路线模板

网页中对单价、数量、工时、折旧、人工、良率等参数的修改只会写入项目数据，不会回写底库。

## 数据兼容与离线使用

- 项目存储键：`electrical_toolkit_part_estimator_v1`
- JSON 数据结构版本：`schemaVersion: 1`
- 所有依赖、底库和样式均为相对路径，禁止改成网络 CDN，否则会破坏纯离线使用。
- 如新增子计算器，在入口 HTML 中加入对应脚本标签即可；脚本加载顺序也是同一分组内的导航显示顺序。

## 发布检查

1. 保证 HTML 引用的 CSS、JS、图片、文档均存在。
2. 用浏览器直接以 `file://` 打开入口 HTML。
3. 验证所有导航项能切换。
4. 验证估价模块的材料/工序/包材添加、模板载入、拖拽排序、清空确认、JSON/Excel 导入导出。
5. 打包时保留完整目录结构和第三方许可证。

## v1.3 工程化调整

- 框架会拒绝重复的计算器 ID，避免导航和模块路由相互覆盖。
- 单个模块渲染异常时显示局部错误信息，不再使整个工作区空白。
- 浏览器会记住上次打开的子计算器。
- 汽车零件估价导入时会补齐缺失字段和明细行 ID；成本计算会限制负数、利用率、回收折价率和良率的有效范围。
- 全站采用低圆角、低阴影、深蓝灰工程主题；导航使用本地单色线性 SVG 图标，不依赖彩色 Emoji、网络字体或在线图标库。
- v1.3.1 起，“继电器 / 保险丝匹配”归入“电气计算”，“塑料件估价”模块已移除。

## v1.4.0 IEC 60664 系统校核

- 电气间隙/爬电距离模块扩展为电芯级、模组级、PACK 级三级独立边界校核。
- 每层支持动态添加关键尺寸、截图、电气间隙/爬电距离类别及合格判定。
- 尺寸公差支持直接上下偏差与多环尺寸链；本版当时默认使用 RSS 3σ，后续版本已扩展多 Sigma 与极值法可选判定。
- 轮廓度和位置度默认按总公差带折算为单侧 `t/2`，普通尺寸公差按 `±t`，其他形位公差按全值贡献，并允许自定义折算系数。
- 报告汇总项目参数、三级标准与所有校核结论，支持 Word `.doc` 下载和浏览器打印为 PDF。
- 系统校核项目存储键：`electrical_toolkit_iec60664_verification_v1`。
