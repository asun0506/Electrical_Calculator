电气工程师综合计算器（含汽车零件模块化估价）
================================================

使用方法
1. 解压整个文件夹，不能只单独取出 HTML 文件。
2. 双击 index.html 或 Electrical_Calculator.html，即可用浏览器离线打开。
3. 左侧导航最下方“成本估算”分组中，选择“汽车零件模块化估价”。

估价数据
- 项目会自动保存在当前浏览器的本地存储中。
- 建议定期使用“导出项目JSON”备份；以后可导入继续估价。
- “当前零件”导入导出只影响正在编辑的零件。
- “整个项目”导入导出包含项目内全部零件。
- Excel导出组件已打包在本地，不需要联网。

注意事项
- 更换浏览器、清理浏览器网站数据或使用隐私模式，可能清除自动保存的数据。
- 底库原始值不会被页面上的临时编辑覆盖；明细参数修改只对当前估价项目生效。
- 本工具为成本估算辅助工具，材料行情、设备工时、良率和采购条件仍需由使用者复核。

电气间隙/爬电距离系统校核
- 支持电芯级、模组级和 PACK 级分别输入系统边界条件。
- 每层可添加多个关键尺寸、截图及直接公差或尺寸链。
- 尺寸链默认按 RSS 3σ 判定，每条关键尺寸也可选择 RSS 4σ、RSS 6σ 或极值法。
- 结果与报告同时显示 3σ、4σ、6σ 和极值参考；切换判定方式会同步重算最小尺寸与结论。
- 页面可导出 Word 报告，或通过浏览器打印保存为 PDF。
- 可导出完整校核 JSON，并在以后导入继续编辑；系统参数、尺寸链和截图会一并备份恢复。
- “清空当前校核”会删除当前浏览器中的三级参数、尺寸与图片，执行前会再次确认。
- 截图会压缩后保存在当前浏览器，图片过多可能达到浏览器存储上限。
